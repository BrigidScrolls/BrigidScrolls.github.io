🎮 TO ADD YOUR GAME:

Open game.html. You have 3 options:

OPTION A (iframe): 
   Create your game as a separate HTML file called "your-game-file.html"
   Save it in the same folder (C:\website)
   The game.html will automatically show it

OPTION B (direct code):
   In game.html, find <!-- OPTION 2 -->
   Replace that section with your game's actual HTML/CSS/JS code

OPTION C (online game):
   If your game is hosted online, replace the iframe src with the URL

🚀 TO PREVIEW LOCALLY:

1. Install "Live Server" extension in VS Code
2. Right-click index.html → "Open with Live Server"
3. Test all pages and links

📤 TO PUBLISH ONLINE (replace your Quarly site):

1. Create GitHub account (free)
2. Create new repository: YOURUSERNAME.github.io
3. Upload all these files to that repository
4. Go to Settings → Pages → Set branch to "main"
5. Your site will be live at: YOURUSERNAME.github.io
